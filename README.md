# Cube Dash

A small Geometry Dash-style endless runner that runs entirely in the browser — no build step, no dependencies.

**Play it:** https://tntexplodiert.github.io/CubeDash/

## Controls
- **Tap** (Space / W / ↑ / Click / Tap): jump, flip, or use an orb you're touching.
- **Hold**: auto-jump (Cube/Robot) or fly & steer (Ship, Wave, Swing).
- **F**: toggle hitboxes · **Esc**: back to menu.

## Game modes
Cube · Ship · Wave · Robot · Ball · Spider · Swing — fly through portals to switch mode.

## Run locally
Just open `index.html` in any modern browser.
